# সূরা আল-হুমাযাহ — তাফসীর উপস্থাপনা

An interactive Bangla presentation on the tafsir of Surah Al-Humazah (Qur'an 104).

**Live:** https://USERNAME.github.io/REPO/

## What's inside

23 slides covering:

- **পরিচিতি ও প্রেক্ষাপট** — the surah at a glance, the meaning of the `فُعَلَة` pattern, the situation in Mecca, the names mentioned in shan-e-nuzul reports, and the usul principle that the ruling is general
- **সম্পূর্ণ সূরা** — full Arabic text with Bangla translation
- **আয়াতভিত্তিক তাফসীর** — all nine ayat, each with a word-by-word breakdown
- **সৌন্দর্য ও শিক্ষা** — the structural symmetry of the surah, lessons, relevance today, and a self-reflection checklist

## Running it

It's a single self-contained HTML file. Open `index.html` in any browser — no build step, no dependencies to install.

**Controls**

| Key | Action |
| --- | --- |
| `←` `→` | previous / next slide |
| `O` | slide index |
| `F` | fullscreen |
| `Esc` | close the index |

Swipe left/right on touch devices.

## Note

Fonts (Amiri for Arabic, Baloo Da 2 / Tiro Bangla / Hind Siliguri for Bangla) load from Google Fonts, so the first load needs an internet connection. Open it once online beforehand and the browser will cache them.

The counting figure on the `عَدَّدَهُ` slide is illustrative only — it is not drawn from any narration. The point of the visual is the repetition, not the amount.
